# Rentop KG × ARCHA POINT — защищённый Telegram MVP

## Статус документа

ТЗ для реализации. Публичная оферта и политика обработки персональных данных перед публикацией проходят проверку юристом Кыргызской Республики.

## Принципы

- ARCHA POINT остаётся ручным инфраструктурным партнёром: API не используется.
- Документы, селфи и чеки не сохраняются в Supabase и не публикуются. Они поступают только в закрытый Telegram-чат Rentop.
- Клиентский PIN-код выдаёт ARCHA POINT по своему регламенту. Rentop передаёт клиенту локацию и инструкции, а не дублирует секретный код без необходимости.
- Решение о выдаче принимает менеджер. Автоматическая оценка документа или селфи не заменяет ручную проверку.

## Клиентский путь

1. Сайт создаёт заявку и открывает бот с одноразовым deep-link.
2. Бот получает номер только системной Telegram-кнопкой `request_contact`.
3. Клиент выбирает тип документа: ID-карта КР (Tunduk), паспорт КР (Tunduk), загранпаспорт либо иностранный паспорт/ВНЖ.
4. Бот собирает обязательный комплект: официальный файл документа, вторую сторону при наличии, селфи-фото и справку о месте жительства. Для иностранцев — паспорт, ВНЖ/регистрация в КР и подтверждение адреса.
5. Бот показывает версию оферты и политику конфиденциальности. Клиент отдельно подтверждает согласие.
6. SMS OTP отправляется на номер, полученный через `request_contact`; клиент вводит его в боте. Код одноразовый, действует 5 минут, имеет максимум 5 попыток и сохраняется только в виде хеша.
7. Админ-группа получает заявку: модель, даты, стоимость, выбранную локацию ARCHA POINT, ФИО, телефон и материалы для проверки.
8. Менеджер одобряет или отклоняет заявку, затем назначает залог под конкретную модель.
9. После проверки оплаты менеджер создаёт заявку для ARCHA POINT: ФИО, номер телефона, выбранная локация и номер заказа. ARCHA POINT резервирует ячейку и выдаёт доступ в своём канале.
10. После открытия ячейки клиент подтверждает состояние: «Всё отлично» или «Есть вопросы». Во втором случае обязательно добавляет комментарий и фото/видео; бот отправляет тревогу в админ-группу.
11. Для возврата менеджер может изменить постамат и ячейку. Клиент загружает короткое видео закрытия ячейки; менеджер подтверждает возврат после получения устройства.

## Электронное согласие и журнал

На один заказ фиксируются: версия оферты, факт прочтения/акцепта, Telegram ID, подтверждённый телефон, момент генерации и верификации OTP, действия менеджера, приёмка и возврат. Сырым OTP, паспортные данные и публичные URL документов в базе не хранятся.

## Политика рисков

- Проверка формата файла не подтверждает подлинность Tunduk-документа или личности на селфи.
- Сомнения, несовпадение данных, признаки подделки или нестандартный кейс переводятся на ручную проверку/отклонение без автоматических обвинений клиента.
- До выдачи фиксируются серийный номер, комплектация, фото состояния и оценочная стоимость ноутбука.
- Решение о залоге индивидуально для каждой заявки.

## Операционное взаимодействие с ARCHA POINT

Rentop передаёт в согласованную закрытую группу только минимум данных: ФИО, номер телефона, выбранный постамат и номер заказа. До старта пилота согласуются: ответственный и резервный контакты Rentop, экстренный номер, часы закладки и забора, срок хранения, правила неявки и действующие локации.

## Необходимая внешняя настройка

Для production SMS OTP требуется выбранный SMS-провайдер, договор/доступы и переменные окружения. Код не должен использовать SMS от ARCHA POINT: это отдельный код доступа к ячейке, не подпись оферты.
