# Nikita KG: SMS OTP после отключения WhatsApp

WhatsApp OTP для Rentop KG отключён. Для входа в личный кабинет и подтверждения
оферты сервис отправляет одноразовые коды обычным SMS от согласованного имени
`RentopKG` через Nikita KG.

## Что должно быть в Vercel

В **Preview** и **Production** укажите:

```text
NIKITA_OTP_CHANNEL=sms
NIKITA_LOGIN=…
NIKITA_PASSWORD=…
NIKITA_SENDER_ID=RentopKG
CUSTOMER_OTP_HMAC_SECRET=…
OFFER_OTP_HMAC_SECRET=…
```

Секреты не добавляются в Git, браузерный JavaScript или переписку. После изменения
переменных требуется новый деплой и один реальный тест входа на номер каждого
оператора.

## Автоматические напоминания об окончании аренды

Ежедневная задача Vercel отправляет SMS клиентам с активной арендой: за день до
даты возврата и в дату возврата. Для её защиты добавьте в **Production** случайное
значение не короче 16 символов:

```text
CRON_SECRET=…
```

Vercel передаёт этот секрет задаче сам. Значение нельзя сообщать клиентам или
помещать в код. На тарифе Hobby задача запускается один раз в день с точностью до
часа, поэтому сообщение является напоминанием, а не точным таймером.
