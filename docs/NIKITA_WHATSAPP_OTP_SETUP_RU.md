# Временный WhatsApp OTP через Nikita KG

## Что реализовано в Rentop

Rentop создаёт одноразовый шестизначный код, хранит только его HMAC, ограничивает
срок жизни десятью минутами и число попыток пятью. Это используется для входа в
кабинет и подтверждения оферты. Интерфейс намеренно говорит «сообщение с кодом»,
а не «SMS»: временный канал может быть WhatsApp.

Для аудита канал фиксируется в событиях оферты через переменную
`NIKITA_OTP_CHANNEL` со значением `whatsapp` или `sms`.

## Что нужно письменно подтвердить у Nikita KG

В официальной открытой документации Nikita описаны SMS XML API и отдельный OTP
API, но параметр WhatsApp там не указан. Поэтому до включения нельзя угадывать
новый URL или XML-поле.

Отправьте им текст:

> Просим временно включить WhatsApp OTP для Rentop KG для входа в личный кабинет
> и подтверждения оферты. Подтвердите, пожалуйста: существующий запрос XML API
> `POST https://smspro.nikita.kg/api/message` с нашими текущими реквизитами будет
> автоматически маршрутизироваться в WhatsApp, или требуется другой endpoint,
> заголовок/поле, API-ключ либо шаблон? Нужны также подтверждение имени аккаунта,
> ограничения частоты и способ тестового сообщения на наш номер.

## После ответа Nikita

1. В Vercel **Preview** задать `NIKITA_OTP_CHANNEL=whatsapp`.
2. Убедиться, что `NIKITA_SMS_LOGIN`, `NIKITA_SMS_PASSWORD`,
   `NIKITA_SMS_SENDER`, `CUSTOMER_OTP_HMAC_SECRET` и
   `OFFER_OTP_HMAC_SECRET` уже заполнены.
3. Сделать один тест входа на собственный номер. Проверить: код пришёл в
   WhatsApp, неверный код отклоняется, правильный создаёт сессию.
4. Включить `OFFER_SMS_CONSENT_REQUIRED=true` только после успешного теста
   входа и отдельно проверить OTP согласия с офертой.
5. Повторить те же переменные и тест на постоянном Production-домене перед
   публичным запуском.

Не включайте `OFFER_SMS_CONSENT_REQUIRED=true`, пока Nikita письменно не
подтвердит маршрут и один реальный тест не пройдёт. WhatsApp OTP — временный
канал доставки кода, а не самостоятельное доказательство квалифицированной
электронной подписи.
